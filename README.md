# Бот крипто-новин для Telegram-канала (бесплатно, на сервере GitHub)

**Что делает.** Каждые ~15 минут проверяет новостную ленту сайта → открывает новые статьи → берёт главное фото → нейросеть (бесплатная Gemini, запасная Groq) пишет резюме на украинском → в канал уходит **сначала фото с заголовком, затем резюме со ссылкой на источник** (у подписи к фото в Telegram лимит 1024 символа, у текста — 4096).

**Почему GitHub Actions.** Бот запускается по расписанию на серверах GitHub, не «засыпает», не требует будильника и не расходует часы Render. Память о том, что уже опубликовано, хранится в вашей Google Таблице (лист «Новини» бот создаёт сам).

## Установка

### 1. Telegram
1. @BotFather → `/newbot` → имя и username (на `bot`) → скопируйте **токен**. Это *отдельный* бот, не тот, что для грузов.
2. Откройте свой канал → **Администраторы → Добавить администратора** → найдите нового бота → оставьте право **«Публикация сообщений»**.
3. **CHANNEL_ID:** для публичного канала это `@username_канала`. Для закрытого нужен числовой id вида `-100…` (скажите, подскажу, как получить).

### 2. Ключ нейросети (бесплатно)
- **Gemini:** aistudio.google.com → *Get API key* → *Create API key*. Это основной вариант.
- **Groq (запасной, по желанию):** console.groq.com → *API Keys* → *Create API Key*.

### 3. Google Таблица для памяти бота
1. Создайте **новую пустую** Google Таблицу (назовите «News bot»).
2. **Настройки доступа** → добавьте адрес робота (`client_email` из вашего JSON-ключа Google, тот же, что у бота для грузов) с ролью **Редактор**.
3. **SHEET_ID** — часть адреса между `/d/` и `/edit`.
4. **GOOGLE_CREDENTIALS_JSON** — всё содержимое того же JSON-файла ключа.

### 4. RSS-лента сайта
Для ForkLog лента проверена: `https://forklog.com/feed`.

Для другого сайта попробуйте добавить к адресу сайта `/feed`, `/rss`, `/rss.xml` или `/feed.xml`; ссылка должна открываться как набор тегов `<item>`. Если RSS нет — используем запасной режим `SITE_URL` (см. ниже) или напишите мне.

### 5. GitHub
1. Создайте **публичный** репозиторий `news-bot` (у публичных репозиториев запуск Actions бесплатный; в коде секретов нет, ключи хранятся в Secrets).
2. **Add file → Upload files** → перетащите **папку `news_bot` и файлы `requirements.txt`, `README.md`**.
3. **Add file → Create new file** → в поле имени впишите `.github/workflows/news.yml` → вставьте содержимое файла `news.yml` из архива → **Commit changes**.

### 6. Секреты
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Для каждой строки: Name и Secret.

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | токен нового бота |
| `CHANNEL_ID` | `@имя_канала` |
| `FEED_URL` | ссылка на RSS |
| `GEMINI_API_KEY` | ключ Gemini |
| `GROQ_API_KEY` | ключ Groq (необязательно) |
| `GOOGLE_CREDENTIALS_JSON` | содержимое JSON-ключа |
| `SHEET_ID` | ID таблицы |
| `ADMIN_CHAT_ID` | ваш Telegram ID, чтобы бот писал в личку об ошибках (необязательно; сначала нажмите Start у нового бота) |

### 7. Пробный запуск
1. Вкладка **Actions** → слева **News** → **Run workflow** → галочка «пробный запуск» оставлена → **Run workflow**.
2. Откройте запуск → шаг **Run news bot**: в логе увидите, какие посты бот *собирался* опубликовать. В канал ничего не уходит.
3. Всё устраивает? Повторите **Run workflow**, но **снимите галочку**: бот опубликует последние 3 новости и дальше работает сам каждые ~15 минут.

## Настройки (необязательно)
**Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `MAX_PER_RUN` | сколько постов за один запуск | 3 |
| `FIRST_RUN_POSTS` | сколько новостей опубликовать при первом запуске | 3 |
| `MAX_AGE_HOURS` | старше этого возраста новости не публикуются | 48 |
| `SUMMARY_MIN` / `SUMMARY_MAX` | длина резюме в символах | 600 / 1800 |
| `TITLE_PREFIX` | значок перед заголовком (`-` = убрать) | 📰 |
| `REPEAT_TITLE` | `0` — не повторять заголовок во втором сообщении | 1 |
| `LLM_ORDER` | порядок нейросетей | gemini,groq |
| `GEMINI_MODELS`, `GROQ_MODELS` | названия моделей через запятую (если Google или Groq сменят модели — впишите актуальные) | см. config.py |
| `SKIP_CATEGORIES` | рубрики ленты, которые не публикуем, через запятую (для ForkLog «Лонгриды» — гостевые и рекламные материалы) | Лонгриды |
| `USE_PHOTOS` | `0` — не брать фото из статей (всё равно ставится ссылка на источник) | 1 |
| `FALLBACK_IMAGE_URL` | своя картинка для постов без фото | — |
| `SITE_URL`, `LINK_REGEX` | режим без RSS: страница со ссылками и шаблон адресов статей | — |

## Важно знать
- **Бесплатные лимиты нейросетей** ограничены и меняются; при 10–30 постах в день их хватает, а запасной провайдер подстрахует. Данные на бесплатных тарифах могут использоваться провайдером, поэтому прогоняем только публичные новости.
- **GitHub отключает расписание**, если в публичном репозитории 60 дней нет активности. Бот сам пытается этого не допустить, но раз в пару месяцев загляните во вкладку Actions: если рядом с News значок паузы, нажмите **Enable workflow**.
- **Запуск по расписанию может опаздывать** на 5–30 минут — для новостей это нормально.
- **Фото принадлежат сайтам-источникам.** Бот всегда ставит ссылку на источник; при росте канала лучше подумать о фотостоках.
- Лист «Новини» растёт примерно на 30 строк в день; раз в год его можно очистить (оставьте последние сотни строк).
